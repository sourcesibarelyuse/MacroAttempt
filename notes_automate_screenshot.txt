```

# Abstract state machine (inferable):

# === ASYNC EXECUTION / HAND-OFF ===
onIntentResult(context, intent):
    code = intent.extra(RESULT_CODE)
    if code != SUCCESS: throw
    token = systemService(MEDIA_PROJECTION).getMediaProjection(code, resultIntent)
    ctx.enqueueWorker( Worker(token, resolvePath(targetPath)) )
    return async                              # caller keeps pending

# === INPUT INJECTION (injection layer stub) ===
# File only references injection via token handle passed to worker.
# Generic pattern:

    capture(handle) -> bytes

    setVar(varImageFile, destination)
    signalComplete()

# === TIMING / DELAY LOOPS ===
# None present. Completion is event/signal-driven (onComplete slot),
# not polled or slept. Flows: enqueue -> worker -> signal -> next.

# === VISITOR (introspection graph walk) ===
visit(visitor):
    visit(onComplete)      # outgoing completion edge
    visit(displayId)       # edge to param source
    ...                    # every slot is a node in the execution graph
```

**Extracted generic engine pieces:**
1. **Declarative config** — field slots + permission resolver keyed on capability/version.
2. **Version-gated binding** — only bind fields when runtime schema >= minimum.
3. **Capability negotiation** — request → pass/fail → handle, via platform result intent.
4. **Async non-blocking hand-off** — enqueue worker with resolved token+destination, return pending.
5. **Result propagation** — worker writes to output slot & raises completion signal (no sleep loops).
6. **Introspection graph** — every param/edge is a visitor-traversable node.
